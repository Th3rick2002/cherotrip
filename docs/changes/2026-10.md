# Bitácora Narrativa — Octubre 2026

Resumen de hitos, arquitectura y entregas durante el mes de inicio y consolidación del MVP de Cherotrip.

---

### Semana 4 (21–25 Octubre 2026) — Despliegue Fase 1 y Definición v3

- **Fundaciones y Despliegue Base:**
  - Setup de Next.js 15, Tailwind CSS y Supabase (proyecto `xrnffirpxbnslwnvudpu`).
  - Creación del schema inicial de base de datos (`listings`, `categories`, tags de búsqueda).
  - Configuración de Serwist para PWA instalable con pantalla fallback offline (`/~offline`).
  - Despliegue continuo en producción vía Vercel con soporte OpenGraph y robots/sitemap dinámico.
- **Interfaces Implementadas (Fase 1 Core):**
  - **P1 Home:** Hero inspirador con buscador, carrusel de colecciones rápidas, sección de próximos eventos y selector por departamentos.
  - **P2 Explorar:** Grid de listings con filtros cruzados e independientes de categoría y departamento.
  - **P3 Ficha Detalle:** Cuadrícula logística 2×2 (horarios, costo, transporte, accesibilidad), botones flotantes de compartir y retroceso, y CTA flotante directo a WhatsApp (`wa.me`).
- **Planificación v3 y Expansión Logística:**
  - Creación del backlog en GitHub para la expansión v3 (Issues #31 a #40).
  - Diseño del schema para `sub_eventos` y `aportes_comunidad`.
  - Reestructuración integral de la documentación del proyecto (`/docs/`).
